# Театр им. Александра Горбунова

Веб-приложение для онлайн-бронирования билетов в театр с системой регистрации и личным кабинетом.

## Технологии

- **Backend:** Flask 2.3.3
- **Database:** SQLite + SQLAlchemy
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Authentication:** Flask-Login + bcrypt
- **Templating:** Jinja2
